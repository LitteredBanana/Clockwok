## Fitur Server

### Spawner
- Spawner **bisa diambil/dikumpulkan** menggunakan Pickaxe dengan enchant **Silk Touch**.

### /shop
- Toko in-game untuk membeli barang-barang **vanilla Minecraft**.

### /ah (Auction House)
- Marketplace antar pemain.
- Bisa menjual item **RPG** maupun item **Vanilla**.

### /enchanter
- Tempat membeli buku **Custom Enchant Cosmic Enchantment**.
- Menggunakan **Minecraft EXP** sebagai mata uang.
